# 01 · 人物资产与局部修复

**下列均为最终设定重建模板，不是逐字历史记录。** 当时实际留存的女性与男性词见 [history/character-prompts.json](history/character-prompts.json) 和 [history/male-prompt.json](history/male-prompt.json)。历史女性词中的蓝瞳已被后续紫瞳要求覆盖。

## 基准人物

先把原契约立绘作为“身份与服装参考”，不要作为姿势参考。生成基准后，后续姿势都同时引用基准和已通过的正面胸像。

```text
用途：为 NancyLu 的音乐 PV 建立稳定人物身份资产。
参考输入：图1为南希露契约原立绘，只参考身份、发色分区、服装、配件；不沿用跳跃、挥手、漂浮姿态。

请绘制同一位成年女性猫亚人，成熟修长的日系游戏人物比例。正面观看时左侧为银白长发、右侧为黑色长发；猫耳内侧电蓝配白绒毛，卷曲白呆毛，黑发侧小白骷髅夹；保留契约科技服高领、肩带、扣件、三角吊坠、蓝色细线、非对称蓝/黑手套与黑白长尾。皮肤统一冰白，虹膜紫色；表情高冷、半垂眼、嘴闭合，没有笑容或腮红。

画一张身份基准板：稳定直立的正面、三分之二侧身与胸像，姿势自然克制。保持服装结构、脸型、猫耳、头发分区在三个视图一致。头发按大束分组，轮廓清晰，便于后续遮罩与字符采样。

风格为高质量平涂版画/剪纸式日系插画，近黑 #080d15、冰白 #f2f5f7、电蓝 #48baff，紫瞳 #b46aef 为局部例外；灰阶只用少量冷灰、排线或网点。不要桃色皮肤、暖橙配色、厚重圆卡通轮廓或Q版比例。干净真实透明背景，无文字、场景、光雾、外发光或投影。保留耳朵、呆毛、发梢和手指，四周留安全空间。
```

## 同一身份的五套女性姿势

每次先复制以下“共同前缀”，再追加表中的单个姿势；一次只生成一张独立人物资产。

```text
用已提供的基准板与已通过的正面胸像保持同一个 NancyLu 身份、脸型、服装硬件、头发分区和画风。成年女性，高冷闭嘴，冰白皮肤、紫瞳、白/黑分发、猫耳、白卷呆毛和白骷髅夹。不要重新套用原立绘的跳跃姿态。

输出一位完整透明背景的人物，除眼部近景外，所有猫耳、呆毛、手指与发梢均在画布内，顶部与左右至少留约10%空间；只允许躯干在底部有意裁切。白肤与紫瞳稳定，蓝色仅在耳部、衣服和手套细节中。无字、无界面、无道具背景、无黑色矩形底板。人物不要自行扩展成多视图或多人。
```

| 姿势 | 追加指令 |
| --- | --- |
| 正面胸像 | 正面头与上半身，肩平、头正、双臂自然放下在画外，平静锐利的视线看向观众；躯干裁至腰部附近。 |
| 三分之二侧身 | 面向画面左侧，略微低头，看向画外对话；克制、疏离。保留正面身份对应的发色分区，不把整个头发变成单色。 |
| 向前伸手 | 身体轻微三分之二转向，一只蓝手套手向画面左下方的观众伸出，掌心向上/前；另一只黑手套手轻放领口。两手各四长指加一拇指，指节和掌心自然。 |
| 双手猫爪 | 双手抬至肩侧，手腕轻向内弯、手指自然弯曲。是人类做猫爪手势，不是动物爪或手套团。每只手明确四根长指与一个对掌拇指，蓝手套在左、黑手套在右；尾巴在肩后自然成S形。表情仍高冷。 |
| 眼部近景 | 紧裁头与颈部，微侧低头，一只紫瞳直视观众，另一眼被自然刘海遮住；鼻、下巴和可见眼完整。保留骷髅夹与黑白发，不加眼罩或激光发光。此姿势允许头发延伸出方形画布。 |

## 五指局部修复

当手部被审核指出四指、拇指融合或关节不清时，编辑对应原透明 PNG，不重画脸与躯干。

```text
仅修复图中双手的人体解剖，不改变身份、脸、眼睛、头发、服装、姿势、比例、构图或透明背景。

优先修复观众右侧黑手套：上方清楚可见四根自然弯曲的长指（食指、中指、无名指、小指），另有一个从掌内侧/较低处独立伸出的对掌拇指，共五指。拇指不能并入食指、掌缘或袖口。左侧蓝手套也核对同样结构。保持克制的猫爪手腕，正常人类掌宽与关节，不要动物肉垫、无指手套、六指或融合手指。

只改必要的局部形状，保留冰白皮肤、紫瞳、黑白蓝画风和真实alpha。输出完整原人物资产的修复版。
```

## 男性无面剪影

```text
参考图1为已通过的女性正面胸像，图2为身份板。生成同一契约黑客猫亚人的成年男性版本，只改变性别轮廓、发型与衣服贴合方式，保留猫耳、黑白分发、骷髅夹、白卷呆毛、三角吊坠与蓝色契约细节。

短而有层次的白/黑分区头发，略宽的平直肩线、男性颈部和有棱角的下颌。高领闭合黑色科技外套完全遮住平胸，不露胸、不保留女性胸部结构。直立正面胸像，双臂在画外，构图和女性胸像接近以便配准切换。

脸是有意设计的完整近黑平面：不画眉、眼、瞳孔、鼻、嘴或五官线条，刘海下方与额头缝隙不得留白色皮肤。保留下颌轮廓和垂下的发丝。高质量细致版画插画，蓝白黑冷灰，真实透明背景，无文字、无光雾、无多视图。
```

## 程序派生的最终统一

```text
不要为了紫瞳或无面切换重生整个人物库。对锁定资产在程序中建立按姿势定义的虹膜区域，仅把该区域中的蓝色像素转为 #b46aef；蓝耳、蓝手套、蓝服装和像素头像保持原色。面部定位必须逐姿势核对，不能把正面眼部坐标复制给侧面。

正常分版中冰白皮肤、紫瞳和暗线从底版开始保留。只有源蓝墨参加头部、衣服、外侧发梢/手套三组叠色。按真实透明轮廓合成，不用矩形近似人体；每次合成结束将源alpha恰好应用一次，避免半透明边缘反复加深。

女性无面版沿暴露脸部、眉眼与刘海之间的额头缝隙描遮罩，填成近黑，保留白色发丝、猫耳和下颌轮廓。不能只遮眼睛或只遮下半张脸。正面普通镜头不使用该遮罩。
```
