# 03 · 分镜与歌词语义特效

**性质：根据最终分镜与修订结果重建的模板。** 以本项目歌曲时间为准；完整成片含 5 秒前置片头。上游视频的段落时间只能作为初始参考。

## 全片编排

```text
保持89个首尾连续的镜头，覆盖歌曲0–211.96秒。先把歌词/关键词、用户操作、对象变化和镜头切点映射为同一张cue表，再写画面。每个大效果都必须有歌词语义或剧情事件作为触发原因。

0–29秒：组装同一个客户端、NancyLu头像上线、参数初始化、契约连接。世界球体与标题镜头加入由角色遮罩采样的蓝白字符立绘；把完整片名放在独立区域，不用大黑标题块挡住半张脸或躯干。

29–74秒：点集、维度、圆、正弦与切线、极限边界；AC波形压缩成DC直线；年份滑杆、Speed与思考强度；角色进入契约版画。大关键词与普通长句分别占空间，长句用蓝白对话窗。

74–104秒：按实际歌词画茄子、番茄、猫与太阳，配合无面F→M与S→M参数。茄子是细长弯曲的轮廓加萼片；番茄是宽圆分瓣果实加五角叶萼与切面，不得都画成不可辨识的圆形水果。

104–148秒：未完输入、离开、离线、保存的对话历史、撤回碎片与拒绝权限。故障从局部扩散，不能提前把所有UI毁掉。右侧字符NancyLu与左侧歌词历史互相留出阅读空间。

148–192.34秒：EXECUTION硬切与计数、代码隧道、线框空间、执行权限反转。让文字、角色和客户端在同一拍点发生因果关联。NEW ORIGIN保留函数和坐标世界，人物字符局部跟鼓点爆发。

192.34秒到结尾：回到完整客户端，权限归属NancyLu，蓝色契约链路稳定，故障与泛光强度逐步下降，按设计淡出。
```

## 契约人物三阶段叠色

```text
参照版画的多段上色，但使用最终NancyLu冷色规则：从第一帧开始保留完整人物暗线、冰白皮肤和紫瞳；把源蓝色像素分成头发/头部、中央服装、外侧发梢/手套细节三组，分别由白色底墨过渡到电蓝。

阶段事件锚点为STIMULATIONS约61.958秒、SATISFACTION约65.397秒、EXECUTION约69.259秒。不要把皮肤当作第一块蓝墨，不用横向或竖向矩形替代人体遮罩。全身轮廓始终完整，叠色只能改变已有墨版，不能产生遮挡脸和躯干的不透明黑方块。
```

## 猫爪 ENJOYMENT

```text
在82.04–85.04秒保留猫爪段：左侧NancyLu由字符形态显影，双手为自然五指猫爪，猫耳警觉竖起，尾巴随拍点摆动；右侧呼噜波形由近到远展开；底部ENJOYMENT按乐句重点落下。

正常表情仍高冷，紫瞳与白肤稳定。字符取样来自同一锁定资产，不重生出另一张脸。波形、人物、关键词与歌词窗分别保留边距，爪子或文字不能被播放器安全区外的构图裁掉。
```

## F → M 无面切换

```text
在90.197–92.015秒使用女性无面胸像与男性无面胸像。让F/M选项状态与人物性别同一进度切换，当前工程的交叉过渡约90.97–91.13秒；重新配音轨时以实际唱句重新核对。

无面需要遮掉整张暴露脸的五官区域及刘海缝隙中的额头、眉眼、白皮肤，保留前景发束、耳朵和下颌轮廓。两个性别都不能残留半块白眼或鼻梁。男性短发、封闭胸口与肩颈轮廓必须清楚。其他镜头继续使用正常人物版。
```

## 年份与太阳的绑定

```text
年份：在51.363–55.083秒，把显示数值、刻度、圆形滑钮、光标和随动标签全部绑定到同一yearToX函数。当前工程范围为-2000至2200，年值约从2026向-2000变化；正年显示AD，负年显示BC。不要写CE/BCE，不给刻度另加一套移动偏移，否则圆钮与数字会错位。这个动画轨道是参数演示，不宣称是严格的无公元0年历史年代表。

太阳：在92.015–96.31秒，半圆轨道和圆形太阳共用圆心(1020,720)、半径500。进度q映射到上半圆theta=PI*(1-q)，x=cx+r*cos(theta)，y=cy-r*sin(theta)。不要把球的位置写成另一个椭圆或直线插值。

分段节奏：92.65–93.953缓慢从0到0.12；93.953–94.22快速到0.5；94.22–94.70停在中点；94.70–95.15快速到1。区间内使用平滑缓入缓出，结束后保持终点。太阳、拖动光标和AM/PM状态按同一q计算。先输出含起点/中点/终点的短片听看核对，再放入全片。
```

## NEW ORIGIN 的人物与函数

```text
在166.50–168.34秒保留原球体、连线、坐标轴、XYZ标签、下方函数和NEW ORIGIN大字。人物由同一NancyLu透明资产采样为蓝白代码字符，置于球体内部或同一空间中；不能用实心矩形盖住函数。

鼓点或起音到来时，只触发约7帧的局部扫描、偏移残影与切片阴影，强度乘低频包络；持续存在的字符人物稳定可读。球体、坐标与人物共用同一镜头变换，歌词放在独立对话窗。
```
