## 共同前缀

提供已通过的 NancyLu 基准、正面胸像，以及需要的猫爪或眼部近景。A 方向再提供原封面，明确它只供版式与视觉机制参考。

```text
为NancyLu·world.execute(me);制作一张16:9横版PV封面。用提供的人物资产保持同一成年女性猫亚人身份：正面观看时左白右黑长发、猫耳、电蓝内耳白绒、白色卷呆毛、黑发侧白骷髅夹、黑色契约服、三角吊坠与蓝色细节。高冷半垂眼，嘴闭合，正常皮肤全部冰白 #f2f5f7，双眼紫色 #b46aef。不能桃色、肉色、橙色或蓝色皮肤，不改变服装结构。

高质量日系游戏插画与冷色版画、代码字符、网点纹理、精确线框、水平切片和电蓝套色偏移结合。主色近黑、冰白、电蓝，紫色只用于虹膜和思考滑杆。保留大块明暗与高对比，手机缩图也能认出人物和标题。

文本必须准确拼写world.execute(me);与NancyLu；标题符号不可丢失，不添加错误字或乱码副标题。人物、标题、关键控件各留独立空间，标题离四边至少约5%，避免手、头发或界面边框盖住字。只做一张独立封面，不做拼贴样张。无水印、平台播放UI或弹幕。
```

## A · 参考构图

```text
参考原封面的大构图和机制：左侧单眼与脸部极近景占约一半，右侧三块错位深色标题条。把橙色参考人物完全替换为NancyLu黑白分发与紫瞳，不复制原人物、花饰或暖橙配色。

眼睛放左侧约三分之一处，瞳孔可含细小代码和星形高光。头发负空间嵌入蓝色代码纹理，少量水平错位切片和电蓝偏移边。右半标题分三行精确为“world.”、“execute”、“(me);”，下方小条“NancyLu / CONTRACT EDITION”。留出充足右边距，不让第三行标点越界。
```

## B · 执行权近景

```text
人物冷静正面头肩近景在右，双紫瞳清晰直视，左侧以巨大白色等宽标题“world.execute(me);”和电蓝条“EXECUTION”建立视觉重心。允许标题分为“world.”和“execute(me);”两行，拼写符号完整。

背景为精确轨道、代码与坐标细线，带克制数据爆发；表达取得执行权的稳定感。标题离左边至少约5%，不挤到边框；人物面部保持冰白，不能被蓝色玻璃或色块染蓝。无手部时不用额外生成手。
```

## C · Codex 对话

```text
左侧为倾斜但可读的深色NancyLu客户端，右侧为高冷的白肤紫瞳人物胸像。客户端显示用户一句“Initialize our world.”，NancyLu回复以准确大字“world.execute(me);”。模型栏有NancyLu、蓝色闪电Speed、思考图标、蓝紫胶囊滑杆和白色圆钮。

输入框、对话与工具栏只出现一套，不重复；界面内容集中清楚，不把代码塞满每一处。人物头发可以自然经过窗口后方，不能挡住标题。若提供原像素头像，必须保持其身份、原色与像素边界；不能擅自替换成不一样的生成Q版头像。可将难以准确复现的小头像区留空以便后续放置原资产。
```

## D · 猫爪 ENJOYMENT

```text
左侧NancyLu双手抬至肩边做克制猫爪手势，一只蓝手套、一只黑手套。每只手清楚为四根弯曲长指加一对掌拇指，共五指。表情仍高冷，猫耳直立，黑白长尾在肩后成S形。脸和胸口裸露皮肤全部冰白，不要暖桃色阴影。

右侧为呼噜波形与巨大衬线“ENJOYMENT”，下方“world.execute(me);”和“NancyLu / CONTRACT EDITION”。完整ENJOYMENT至少保留5%右边距；宁可减小字号和调整左右分区，也不要把最后一个T切掉。左边黑手不能盖住首字母E。波形保持标题上方，人物、手、标题都完整可读。
```

## 常用局部修订

```text
仅编辑人物裸露皮肤区域，将偏桃/肉色统一为冰白 #f2f5f7，保留冷灰结构阴影；不要改变紫瞳、头发、表情、服装、手套、波形、标题和构图，不要把皮肤改成蓝色。输出完整封面。
```

```text
仅修正标题与安全边距：ENJOYMENT精确拼写且完整显示，左右均有约5%安全空间；缩小并向内收，而不是向画布外挪。人物和黑手保持原身份与姿势，但不要遮住首字母。其余内容、白肤、紫瞳、配色和质感保持不变。
```
