# 07 · 审核问题与最小修复词

**性质：根据实际审核问题和最终实现重建，不是用户原话或逐字工具日志。** 对应问题未出现时不要重复执行这些修复。先确定是原图、遮罩、坐标、镜头还是合成次序的问题，再选择一段。

## 人物有一半被黑块挡住

```text
定位人物分版与镜头clip，不重生人物。删除用矩形模拟人体/上色的黑色覆盖；以原透明alpha与真实源墨像素分版，保证完整暗线和冰白皮肤从第一帧可见。只有原蓝墨参加三阶段上色，紫瞳保持。自由胸像的相机开口随退镜释放到原构图，不能用固定内部矩形切掉脸或躯干。输出问题时刻前后和近/中/远对照帧，确认没有新的硬遮挡。
```

## 无面段残留白眼或额头

```text
只修改女性无面派生版的面部遮罩：完整覆盖眼眉、鼻嘴、脸缘与刘海缝隙中的暴露额头，填为近黑。保留遮在前面的白色发束、猫耳、骷髅夹与下颌轮廓，不能把整片刘海涂黑。男性版也核对不存在五官。正常人物版与其他镜头不变。对F/M切换前、中、后各输出一帧并放大检查。
```

## 正常肤色偏蓝或桃色

```text
正常皮肤采用完整print版的冰白墨，不参与局部电蓝叠色，不接受暖桃色插画皮肤。修正源像素分组或局部生成编辑，避免全局色相调整把蓝手套/服装一起改色。紫瞳保持，只在定义好的虹膜范围内着色。重点核对契约签署、模拟沙盒和正常侧身三个镜头肤色一致。
```

## 左侧字幕单调、没有完整问答

```text
使用用户完整LRC的真实当前句与最近历史替代零散剧情字；将函数和人物旁长句统一为蓝白浮动Codex对话窗，USER/NancyLu角色清楚。逐字切换type、decode、scan、rise、packet、glitch，但最终句子稳定。正文高度不够先删代码，不删当前歌词；输入框只在文本带输入，不盖Speed/思考栏。用实际播放短片检查可读性。
```

## UI 重复或工具栏被遮

```text
检查同一帧是否画了两次完整客户端或两套composer。组装只拆同一客户端的六块互斥区域，clip先于区域偏移，结束后一次drawClient。歌词历史、正文与输入框必须复用现有布局，不能再叠一套仿制UI。输入文本和工具栏分区裁切，光标和文字不得覆盖旋钮、Speed或发送按钮。输出早期组装和103–106秒的实际帧检查。
```

## 太阳、年份与按钮脱轨

```text
为物体和轨道建立唯一几何映射，不用两套近似坐标：年份显示、刻度、圆钮、光标、提示值都走yearToX；正年AD、负年BC。太阳与半圆共享cx/cy/r/q，光标跟随同一个q，动作按慢行→快到中间→短暂停留→快到结尾。相机变换也必须包含整个相关组，不能只移动轨道或按钮。输出连续短片，不只看终点截图。
```

## 开场与世界球体过空

```text
在世界初始化和标题场景加同一NancyLu的程序字符立绘：从透明人物墨色采样，保留白/黑分发与紫瞳对应层次。用鼓点或起音驱动窄带残影与扫描，整体轮廓常驻稳定；保留原函数和球体，完整片名移到独立下方区域。不要用大黑块衬标题盖掉半个人物。
```

## 全片没有视角变化

```text
按camera.js的23个选定场景补近景→中景→原全景，而不是全片统一缩放。文字与阅读区稳定，关联几何共用同一镜头变换，切点前归位。重点输出眼睛/手/切点的近景，随后显示其所属人物或系统；检查clip不会把人硬切半边。保留安静对话和F/M等需要阅读的静止镜头。
```

## 高潮效果脱离歌词

```text
先把当前乐句的语义、关键词、动作与对象写成cue，再选特效。删除对应撤回/抹除，执行对应代码与权限，原点对应坐标重置。保留NEW ORIGIN函数、球体、轴与XYZ，把字符NancyLu放进同一空间，鼓点只控制局部7帧扫描/残影的启动与强度。去掉没有语义原因的全屏噪声和持续闪烁，用短片核对拍点。
```

修复后只重新核对受影响镜头及其转场；在正式全片验证前，不把局部通过当作整片已经通过。
