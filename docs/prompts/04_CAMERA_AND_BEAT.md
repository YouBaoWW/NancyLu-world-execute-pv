# 04 · 运镜与音乐响应

**性质：按 `src/nancy/camera.js` 和最终字符特效重建的模板。** 最终工程有 23 个运镜场景条目，不等于每个镜头都在移动。

## 可复制运镜指令

```text
在选定场景插入有目的的“主体近景 → 中景 → 原全局构图”，让观众先看清对象细节，再理解其空间。使用现有绘制层的坐标变换，不放大一张已经合成完的截图，不复制另一套UI。

以130 BPM的STEP=60/130秒为基础。场景起始停留约半拍近景，在第二拍进入中景，在第四拍内回到原构图；短镜头按时长缩短并至少为切点归位留下约0.18秒。中景倍率为1+(近景倍率-1)*0.20，段内缓入缓出，切镜前恰好回到zoom=1。

人物近景以脸、伸出的手或猫爪为焦点；数学镜头以切点/曲率等信息为焦点；控制镜头只做轻微推拉。字幕、对话阅读区和工具栏标签保持固定字号与清晰位置。安静对话、计数与F/M切换保持稳定，不为移动而移动。

人物、几何、控件、背景是独立的layer。曲线、切线、切点和光标必须共享diagram镜头；年份数值、刻度、圆钮共享controls镜头；NEW ORIGIN球体、轴和XYZ标签共享geometry镜头，人物在同一视点下配准。不能只移动太阳或某个按钮而把轨道留在另一坐标空间。

观看窗口先clip，再translate/scale焦点对象；人物自由胸像可逐步释放到整个画布，不用固定内部矩形把人切成两半。绘制后用save/restore恢复Canvas状态。clip、位移和缩放均由绝对时间计算，快速拖时间轴或反向跳转不改变结果。
```

## 可复制鼓点响应指令

```text
优先读取已有features.sample(t)的beatPulse、sinceBeat、sinceOnset、lowEnv；歌曲与分析数据必须同一时间基准。130BPM网格可做回退，当前工程网格初相位约0.344秒，但不能把该数值套给新音源。

字符人物由透明图像内部取样，字符与源颜色一一对应，固定网格与种子。人物基底维持稳定。重鼓点触发窄带扫描、少量横向残影或径向碎片，低频控制强度；起音可以触发更细的字符闪现。高潮包络约6–8帧，随后快速回到稳定状态。

歌词意义决定效果：删除对应字符撤回；太阳对应昼夜拖动；性别对应F/M；EXECUTION对应权限、计数和代码执行；NEW ORIGIN对应坐标重置。不要将所有效果都简化成每拍全屏亮灭，也不要让对白处持续摇晃。

输出近景/中景/全景三个时间点的对照板及短片，检查关联对象同轨、文字清楚、人物没有硬裁切、局部响应跟随鼓点。相机状态与粒子状态必须对任意跳转可复现。
```
