# NancyLu 封面套装

四张均使用内置 ImageGen 生成，原生 PNG 为 **1672×941、RGB**，没有把放大分辨率冒充原生输出。

| 文件 | 方向 |
| --- | --- |
| [01_reference_composition.png](01_reference_composition.png) | 单眼近景、错位代码标题，最接近参考封面的构图 |
| [02_execution.png](02_execution.png) | 双眼高冷近景、执行权主题 |
| [03_codex_dialogue.png](03_codex_dialogue.png) | NancyLu 对话、Speed 闪电与强度滑杆 |

统一使用白肤、紫瞳、黑白分发与蓝白黑配色。C 的小头像是生成的封面插图，影片中使用的指定像素头像仍由程序独立绘制。标题、人物、双手五指与画面边缘经过目视检查；不同平台会再次裁切，上传时请检查预览。

初始生成词和后续局部修改见 [封面记录](../prompts/history/covers-prompts.json)，可复制模板见 [封面指南](../prompts/06_COVERS.md)。参考封面的原图地址、作者与许可见 [第三方声明](../THIRD_PARTY_NOTICES.md)，本公开包不附该参考原图。
