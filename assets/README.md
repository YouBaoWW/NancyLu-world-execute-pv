# 人物素材

`nancy/master-v1.png` 是人物一致性基准；其余 PNG 是运行时使用的胸像、侧面、伸手、猫爪、眼部与男性姿势。

人物为本项目 AI 辅助生成的南希露契约皮同人图像。生成提示词见 [人物提示词](../docs/prompts/01_CHARACTER_ASSETS.md) 与 [历史记录](../docs/prompts/history/character-prompts.json)。原始 PNG 中的部分虹膜仍为蓝色；最终 PV 在 `src/nancy/asset-character.js` 中按姿势区域映射为紫色，并进行冰白皮肤、暗线与源蓝墨的独立分版。

角色图像、指定像素头像以及角色设计不因存于源码目录而成为 MIT 素材。第三方角色设计与商标保留原权利；本发布未为这些位图或头像另行授予素材再许可，详见 [素材范围](../docs/ASSET_POLICY.md)。
